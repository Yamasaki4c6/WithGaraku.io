# WithGaraku — GLSL Effect Exporter

イラストの演出に使うエフェクトを GLSL で書いて、**背景透過の PNG（単体・連番）**で書き出すためのブラウザツールです。

公開ページ: https://yamasaki4c6.github.io/WithGaraku.io/

## 使い方

1. 左のエディタに Shadertoy と同じ `mainImage(out vec4 fragColor, in vec2 fragCoord)` 形式でシェーダーを書きます（Ctrl/⌘+Enter でコンパイル。自動コンパイルもあります）。
2. `fragColor` のアルファがそのまま PNG の透過になります。
3. 解像度・fps・長さを決めて「連番をZIPで書き出し」を押します。Chrome / Edge なら「フォルダへ書き出し」で、指定したフォルダに直接保存することもできます。

### プロジェクトの保存

下部の「プロジェクト」から、レイヤー構成・画像・GLSL・出力設定をまとめた **`.glslfx` ファイル**（中身は project.json と画像を入れた ZIP）を保存・読み込みできます。

- 保存：Ctrl/⌘+S、別名で保存：Ctrl/⌘+Shift+S、開く：Ctrl/⌘+O。`.glslfx` をプレビューにドロップしても開けます
- Chrome / Edge では保存先を選べ、2回目以降の保存は同じファイルへの上書きになります。それ以外のブラウザではダウンロードとして保存されます
- 保存していない変更があると、プロジェクト名の横に ● が付きます
- 「最近 ▾」から、最近保存・読み込みしたプロジェクト（最大12件、サムネイル付き）をすぐ開けます。Chrome / Edge では元のファイルを開き直し、開けないときやほかのブラウザでは、最後に保存・読み込みした時点のコピーから開きます
- これとは別に、作業中の状態はブラウザ内にも自動保存されます（同じブラウザで開き直すと続きから再開）

### レイヤー


右側のレイヤーパネルで、**画像レイヤー**と **GLSL レイヤー**を重ねられます（上にあるものが手前）。

- 追加：「＋GLSL」「＋画像」。画像はプレビューへのドラッグ＆ドロップや Ctrl/⌘+V の貼り付けでも追加できます
- 並び替え：レイヤーをドラッグ。目のアイコンで表示／非表示、ダブルクリックで名前の変更
- **フォルダ**：「＋フォルダ」で追加、Ctrl/⌘+G で選択中のレイヤーをフォルダに入れる。フォルダの行の真ん中にドロップすると中に入ります。合成モードは既定が「通過」（中身がそのまま下に重なる）。通常などに変えると、中身をまとめてから合成されます。不透明度・加工・クリッピングもフォルダ単位でかけられます
- **描画レイヤー**：「＋描画」で追加。ペン・消しゴム・投げ縄で描けます
- **クリッピング**：「クリッピング」ボタンまたは Ctrl/⌘+Alt+G。すぐ下のレイヤー（下地）の不透明な部分だけに描かれます。下地の合成モード・不透明度がグループ全体にかかり、下地を非表示にするとクリッピングしたレイヤーも消えます
- **合成モード**：通常／置き換え／比較（暗）／乗算／焼き込みカラー／焼き込み（リニア）／減算／比較（明）／スクリーン／覆い焼きカラー／覆い焼き（発光）／加算／加算（発光）／オーバーレイ／ソフトライト／ハードライト／ビビッドライト／リニアライト／ピンライト／ハードミックス／差の絶対値／除外／除算／色相／彩度／カラー／輝度
- **加工**（レイヤーごと）：白抜き・黒抜き、レイヤーカラー（単色化）、明るさ・コントラスト・色相・彩度・明度、階調化、色の反転、フチ（太さ・色）、ぼかし
- 取り消し／やり直し：Ctrl/⌘+Z、Ctrl/⌘+Shift+Z（コードの編集はエディタ側の取り消し）
- GLSL レイヤーの `iChannel0` は「そのレイヤーより下の合成結果」です（クリッピング中はクリッピング先から上）。合成を「置き換え」にすると、下の絵を歪ませるようなエフェクトが作れます（サンプル「陽炎」）
- 書き出されるのは**表示中のレイヤーだけ**です。エフェクトだけを透過で書き出したいときは、イラストのレイヤーを非表示にしてください
- レイヤー構成と画像はブラウザ内に自動保存されます

### ツール

プレビュー左上のツールバー、またはキーで切り替えます。

| ツール | キー | 内容 |
|---|---|---|
| 移動・変形 | V | 画像・描画レイヤーの移動・拡大縮小・回転（下の表） |
| ペン | P | 描画レイヤーに描く（色・サイズ・不透明度・筆圧）。描画レイヤー以外を選んでいるときは新しい描画レイヤーを作ります |
| 消しゴム | E | 描画レイヤーを消す |
| 投げ縄 | L | 囲んだ範囲を塗りつぶす／消す |
| 手のひら | H（または Space 押しっぱなし） | 表示の移動 |

`[` `]` でブラシサイズを変更できます。

### 画面

- エディタとプレビューの間の仕切りをドラッグすると、幅の比率を変えられます。ダブルクリックするとエディタを閉じたり開いたりできます
- 出力の「比率」「長辺」のプルダウンで、16:9・9:16・1:1・4:3・3:2・4:5・21:9・A判などに切り替えられます。⇄ で縦横を入れ替えます

### 画像の変形（クリスタの「拡大・縮小・回転」に近い操作）

| 操作 | 内容 |
|---|---|
| 枠の内側をドラッグ | 移動（Shift で水平・垂直に固定） |
| □ ハンドルをドラッグ | 拡大縮小。四隅は縦横比固定（Shift で切り替え）、Alt で中心基準。反対側まで引くと反転 |
| 枠の外をドラッグ | 回転（Shift で 15° 刻み） |
| 矢印キー | 1px 移動（Shift で 10px） |
| Ctrl/⌘ + クリック | クリックした位置の画像レイヤーを選択 |
| ホイール | 表示倍率（カーソル位置を中心に拡大縮小） |
| Space + ドラッグ／中ボタンドラッグ | 表示のスクロール |
| Ctrl/⌘+0 ／ Ctrl/⌘+Alt+0 | 全体表示 ／ 100% 表示 |
| Delete | 選択中のレイヤーを削除 |

パネルからは、中心位置（px）・幅／高さ（%）・回転角の数値入力、左右・上下反転、リセット、キャンバスに合わせる、出力サイズを画像に合わせる、補間方法（なめらか／ニアレストネイバー）を設定できます。

### アルファの扱い

| モード | 書き方 | 向いているもの |
|---|---|---|
| straight | `vec4(col, a)` | 煙・墨・影など、不透明感のあるもの |
| premultiplied | `vec4(col * a, a)` | 光を足し算で重ねていくシェーダー |
| 黒背景（出力設定） | — | 発光・火花・ブルーム。クリスタで「加算（発光）」「スクリーン」にして乗せる |

### 使える uniform

`iResolution` `iTime` `iTimeDelta` `iFrame` `iFrameRate` `iMouse` `iDate` `iChannel0`（下のレイヤーの合成結果） `iChannelResolution[0]`、独自に `iDuration`（書き出す長さの秒数）があります。`fract(iTime / iDuration)` を使うと、ループがきれいに繋がります。

### プレビュー

プレビューの背景（市松模様・黒・白・単色）は確認用で、書き出しには含まれません。

## 連番を動画にする（ffmpeg）

```bash
# ProRes 4444（透過あり）
ffmpeg -framerate 30 -i frame_%04d.png -c:v prores_ks -profile:v 4444 -pix_fmt yuva444p10le out.mov
# WebM VP9（透過あり）
ffmpeg -framerate 30 -i frame_%04d.png -c:v libvpx-vp9 -pix_fmt yuva420p -b:v 0 -crf 20 out.webm
```

## ローカルで動かす

`index.html` 1枚だけで動きます。ダブルクリックで開いても動きますが、画像の読み込みで問題が出る場合は `npx serve` などのローカルサーバー経由で開いてください。
